# Kanji Practice

An accessible study website for the 200 prescribed kanji: stroke order, readings, example words and sentences, quizzes, a look-alike game and a printable booklet.

No build step, no accounts, no tracking. Settings and progress are saved in the student's own browser only.

## Publish with GitHub Pages
1. Create a new repository on GitHub (public).
2. Upload everything in this folder (keep the `css`, `js`, `fonts`, `downloads`, `slides` folders).
3. Settings > Pages > Build and deployment > Deploy from a branch > `main` / `(root)` > Save.
4. After a minute the site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Accessibility
Keyboard operable, skip link, screen-reader labels and live announcements, light/dark/high-contrast themes, text size to 200%, easy-read and dyslexia-friendly fonts, spacing options, furigana on/off and size, read-aloud (device voice), reduce-motion, no timers.
